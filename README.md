# D380-openshift-homelab
This is the homelab environment I use to prepare myself for the following openshift certifications:

- Red Hat Certified Technologist in OpenShift (D180)
- Red Hat Certified System Administrator in OpenShift (D280)
- Red Hat OpenShift Administration III (D380)

This is not a production ready deployment, the lab is optimized for learning only.

Feel free to learn, use and modify it.
